# Evaluations

Evaluations retain substantive reviews of a specific proposal or legal-state revision. They may be produced by humans, AI systems or mixed teams.

An evaluation is evidence of a review having occurred. It is not a vote, legal authority or proof that the reviewed proposal is correct. Similar outputs from several models do not create consensus.

There are no evaluation records in v0.1.

## Review types

The format supports focused review such as:

- consistency review;
- rights and principles review;
- adversarial review;
- drafting ambiguity review;
- dependency review;
- synthetic case application;
- institutional feasibility review.

## File format

Copy [TEMPLATE.md](TEMPLATE.md) to a file whose name identifies the reviewed proposal and review sequence, for example `NJ-P-0001-review-01.md`.

Record the exact proposal revision reviewed, reviewer type, system identity when applicable, criteria, findings, limitations and authorship. Do not claim a model version or complete review when that provenance was not captured.

External model calls are not required by v0.1 validation or CI.
